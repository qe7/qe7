# Attention Is All You Need

**Eternal**, Eternal Industries (NDA expired, apparently)

## Abstract

The dominant sequence-transduction models rely on recurrence, convolutions and staying awake. We propose a new architecture, the **Transformer**, which drops all three in favour of naps. While asleep, the author holds a heavy metal ball. When it falls, it wakes him at the exact moment of peak hypnagogic insight, and a great idea is caught. Experiments show this beats every previous method of having ideas, including thinking.

## 1. Introduction

In 2017, a 2021 Minecraft developer travelled back in time. Section 4 explains how this does not create a paradox. Upon arrival, he noticed that recurrent neural networks were "a bit mid". He fell asleep on the spot, dropped the ball and woke up holding self-attention.

## 2. Architecture

- **Encoder:** reads the input sequence.
- **Decoder:** writes the output sequence.
- **Multi-Head Attention:** like attention, but with several heads. Inspired by the Scaffold module co-written with W4z3d.
- **Positional Encoding:** sine waves, because the author once fell asleep watching a speed module's motion graph.
- **HWID Layer:** salted with `"my name jef"`. It does nothing, but removing it makes training feel worse.
